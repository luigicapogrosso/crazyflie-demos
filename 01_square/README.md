# Demo 01 - Square

## Description

Fly a small 35 cm square using the blocking relative-motion primitives in MotionCommander.

**Type:** Flight

## What You Need

Crazyflie 2.1+, Crazyradio 2.0, Flow Deck V2, charged battery, clear indoor flight area.

## Quick Start

From the repository root:

```bash
python -m 01_square.main
```

## What Happens

- Takes off to 0.30 m.
- Moves forward, right, back and left by 0.35 m.
- Returns approximately to the starting point.
- Lands.
