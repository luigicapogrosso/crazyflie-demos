# Demo 05 - Yaw turns

## Description

Hover in place and perform four 90-degree yaw rotations to demonstrate heading control.

**Type:** Flight

## What You Need

Crazyflie 2.1+, Crazyradio 2.0, Flow Deck V2, charged battery, clear indoor flight area.

## Quick Start

From the repository root:

```bash
python -m 05_yaw_turns.main
```

## What Happens

- Takes off.
- Turns left by 90 degrees four times.
- Pauses between turns.
- Lands with approximately the original heading.
