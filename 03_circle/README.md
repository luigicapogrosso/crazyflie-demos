# Demo 03 - Circle

## Description

Fly one clockwise circle using MotionCommander circle primitives.

**Type:** Flight

## What You Need

Crazyflie 2.1+, Crazyradio 2.0, Flow Deck V2, charged battery, clear indoor flight area.

## Quick Start

From the repository root:

```bash
python -m 03_circle.main
```

## What Happens

- Takes off.
- Flies a circle with a 0.45 m radius.
- Stops and hovers briefly.
- Lands.
