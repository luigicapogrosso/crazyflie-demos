# Demo 04 - Figure eight

## Description

Fly two adjacent circles in opposite directions to form a compact figure-eight trajectory.

**Type:** Flight

## What You Need

Crazyflie 2.1+, Crazyradio 2.0, Flow Deck V2, charged battery, clear indoor flight area.

## Quick Start

From the repository root:

```bash
python -m 04_figure_eight.main
```

## What Happens

- Takes off.
- Flies one counter-clockwise circle.
- Flies one clockwise circle.
- Lands.
