# Demo 02 - Rectangle

## Description

Fly a 70 cm by 30 cm rectangle to compare tracking accuracy on two different leg lengths.

**Type:** Flight

## What You Need

Crazyflie 2.1+, Crazyradio 2.0, Flow Deck V2, charged battery, clear indoor flight area.

## Quick Start

From the repository root:

```bash
python -m 02_rectangle.main
```

## What Happens

- Takes off.
- Flies two 0.50 m legs and two 0.30 m legs.
- Lands near the starting point.
